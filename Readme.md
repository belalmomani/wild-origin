# WILD ORIGIN: BEGINNING OF THE WORLD (v0.1 — Vertical Slice)

لعبة بقاء وبناء ثلاثية الأبعاد بمنظور الشخص الثالث لأندرويد. **المحرك: Godot 4.3 (GDScript, renderer: Mobile)**.
السبب: يُبنى APK عبر سطر أوامر في GitHub Actions بلا Android Studio، ويعمل جيدًا على الهواتف المتوسطة.

## ما هو منفّذ فعليًا (كتابةً — لم يُشغَّل بعد)
- عالم 3D إجرائي: تضاريس، 170 شجرة، 60 صخرة، عشب، شمس وظلال، دورة ليل/نهار (12 دقيقة = يوم)، ضباب.
- لاعب بمنظور ثالث، عصا افتراضية، سحب للكاميرا، قفز، تصادمات.
- جمع الخشب والحجر، مخزون، خبرة ومستوى، مشعل (2 خشب).
- بناء المنزل قطعةً قطعة (20 قطعة: أعمدة سداسية، ألواح، عتبات، مثلثات جملون، ألواح سقف) مع معاينة شفافة (أخضر=مطابق/أحمر=غير مطابق)، تدوير 15°، رفع/خفض، 3 مساعدات ثم إعلان مكافأة اختياري.
- السور: 19 حجرًا بأحجام مختلفة (4 أنواع) بنفس النظام.
- حفظ محلي (موقع، موارد، القطع المثبتة، الأشجار المقطوعة، الوقت، المرحلة)، حفظ تلقائي كل 30 ث وعند الإيقاف، لعبة جديدة/متابعة.
- جودة منخفضة/متوسطة/عالية، كتم الصوت، واجهة عربية RTL، دليل أول تشغيل.
- GitHub Actions يبني APK ويرفعه كـ artifact.

## غير منفّذ بعد (مخطط فقط — لا تعتبره مكتملًا)
الصيد والحيوانات والأسلحة، الحظيرة والمزرعة والحيوانات، زراعة التفاح وسقيها، شجرة التقنيات، تحميل العالم على أجزاء (العالم الحالي قطعة واحدة 200×200م)، الصوت، الإنجليزية، إعدادات تخفيف العنف (تأتي مع الصيد).

## البناء
1. ارفع المجلد إلى GitHub (انظر أدناه). 2. تبويب Actions ← Build Android APK ← Run workflow. 3. نزّل `wild-origin-apk` من Artifacts.
- التوقيع النهائي: أضف Secrets: `RELEASE_KEYSTORE_BASE64`, `RELEASE_KEY_ALIAS`, `RELEASE_KEYSTORE_PASSWORD`.

## الرفع من الهاتف (Termux)
```
pkg install git
cd wild-origin && git init && git add . && git commit -m "init"
git branch -M main
git remote add origin https://github.com/<user>/wild-origin.git
git push -u origin main   # استخدم Personal Access Token ككلمة مرور
```

## التحكم
عصا يسار = حركة، سحب يمين = كاميرا، «تفاعل» = جمع، «بناء» = وضع التركيب (القطعة تظهر أمامك على بعد 3م: تحرّك واستدر ثم اضبط التدوير والارتفاع).
