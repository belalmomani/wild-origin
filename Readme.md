# WILD ORIGIN: BEGINNING OF THE WORLD (v0.1 — Vertical Slice)

لعبة بقاء وبناء ثلاثية الأبعاد بمنظور الشخص الثالث لأندرويد. **المحرك: Godot 4.3 (GDScript, renderer: Mobile)**.
السبب: يُبنى APK عبر سطر أوامر في GitHub Actions بلا Android Studio، ويعمل جيدًا على الهواتف المتوسطة.

## ما هو منفّذ
- عالم 3D إجرائي محدود بحلقة جبال (لا انتقال لمناطق بعيدة): تضاريس، 170 شجرة من 6 أنواع (أخضر، خريفي، صنوبر، مزهر، نخلة، أحمر)، صخور، عشب وأزهار، ظلال، ليل/نهار (12 د = يوم).
- بطل بجسم إجرائي يحرّك يديه ورجليه أثناء المشي ويحمل فأسًا.
- جمع حجارة (6 لكل صخرة) وخشب (3 لكل شجرة).
- **البناء كلعبة تركيب بالسحب والإفلات**: زر «بناء» يفتح لوحة الواجهة بفراغات مرسومة بخطوط خفيفة؛ اسحب قطعة حجرية من الأسفل وأفلتها في الفراغ المطابق لشكلها، فتثبت وتظهر في العالم كقطعة 3D حقيقية. زر «تلميح» (3 مجانًا ثم إعلان مكافأة اختياري) يُومض الموضع الصحيح.
- كاميرا سينمائية فوق الكتف مع مدخل تصويري بشريطين سوداوين، وألوان بدرجة Filmic.
- بطل واقعي: ضع `assets/hero/hero.glb` (انظر README داخل المجلد)؛ وإلا يُستخدم جسم مبسّط متحرك.
- الترتيب: واجهة أمامية بباب ← يمنى بنافذة ← خلفية ← يسرى بنافذة ← السقف (4 قطع خشب) ← السور (4 جوانب بفتحة بوابة).
- حفظ تلقائي ويدوي، جودة، كتم صوت، واجهة عربية RTL.

## غير منفّذ بعد
الصيد، الحظيرة، الزراعة، شجرة التقنيات، الصوت، الإنجليزية، إعلانات Start.io الحقيقية.
نماذج الشخصية/الأشجار الواقعية في صور المرجع تحتاج أصولًا مرخّصة (glb) تُضاف لاحقًا في `assets/`.

## البناء
1. ارفع المجلد إلى GitHub (انظر أدناه). 2. تبويب Actions ← Build Android APK ← Run workflow. 3. نزّل `wild-origin-apk` من Artifacts.
- التوقيع النهائي: أضف Secrets: `RELEASE_KEYSTORE_BASE64`, `RELEASE_KEY_ALIAS`, `RELEASE_KEYSTORE_PASSWORD`.

## الرفع من الهاتف (Termux)
```
pkg install git
cd wild-origin && git init && git add . && git commit -m "init"
git branch -M main
git remote add origin https://github.com/<user>/wild-origin.git
git push -u origin main   # استخدم Personal Access Token ككلمة مرور
```
