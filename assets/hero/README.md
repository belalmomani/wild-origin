# البطل الواقعي (اختياري)
ضع ملف نموذج رجل واقعي مربوط بهيكل عظمي باسم **`hero.glb`** في هذا المجلد، وسيستخدمه اللعبة تلقائيًا بدل الجسم المبسّط.
- الطول المناسب ≈ 1.8 متر، ويفضّل أن يحتوي الملف على حركات تحمل في أسمائها `idle` و`walk` و`run` (يكفي `walk`).
- مصادر مقترحة (تحقّق من الترخيص بنفسك قبل الاستخدام): Mixamo (مجاني بحساب Adobe)، Quaternius (CC0)، Sketchfab (فلتر CC0/CC-BY).
- سجّل المصدر والترخيص في `docs/ASSETS.md`.
- يمكنك رفع الملف من متصفح الهاتف عبر GitHub ← Add file ← Upload files، ثم يبنيه الـ workflow.
