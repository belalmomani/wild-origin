# مصادر الأصول وتراخيصها
لا توجد أصول خارجية. التضاريس والأشجار والصخور والعشب والقطع والشخصية تُولَّد برمجيًا من أشكال Godot الأساسية (ملك المشروع، MIT).
الخط: يُستخدم خط النظام في أندرويد للعربية. إن ظهرت مربعات بدل الحروف أضف خط Noto Sans Arabic (ترخيص OFL) إلى `assets/fonts/` وعيّنه كخط افتراضي.
