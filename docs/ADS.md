# الإعلانات (Start.io) — حالة التكامل
- كل منطق اللعبة يتعامل فقط مع `scripts/ads.gd` (`Ads.is_available()`, `Ads.show_rewarded("hint")`, الإشارة `reward_granted`).
- في نسخة **debug** بلا إضافة: محاكاة تطوير واضحة (الرسالة تقول «محاكاة تطوير») — ليست إعلانًا حقيقيًا ولا تمنع اللعب.
- في نسخة **release**: لا تظهر أي إعلانات إلا إذا وُجدت إضافة أندرويد باسم `StartioAds`.
- **لم أتحقق** من وجود إضافة Godot رسمية من Start.io (لا إنترنت في بيئة التطوير). المطلوب منك: مراجعة وثائق Start.io الحالية، ثم إما إضافة Godot Android plugin (AAR) تغلّف الـSDK الرسمي، وتستدعي `Ads.on_reward(placement)` عند اكتمال المشاهدة.
- مفتاح التطبيق (App ID) يوضع كـ GitHub Secret أو في ملف إعداد محلي غير مرفوع. لا تضعه في المستودع.
