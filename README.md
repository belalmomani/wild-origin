# WILD ORIGIN: BEGINNING OF THE WORLD (v0.1 — Vertical Slice)

لعبة بقاء وبناء ثلاثية الأبعاد بمنظور الشخص الثالث لأندرويد. **المحرك: Godot 4.3 (GDScript, renderer: Mobile)**.
السبب: يُبنى APK عبر سطر أوامر في GitHub Actions بلا Android Studio، ويعمل جيدًا على الهواتف المتوسطة.

## ما هو منفّذ
- **تضاريس بخامات حقيقية**: شادر يمزج أربع طبقات (عشب، تربة، حصى، صخر) مع خرائط Normal، وتوزيع حسب الميل والارتفاع، وحلقة جبال تحدّ العالم.
- **أشجار مفصّلة** (صنوبر، بلوط، تفاح بثمار، زيتون، نخيل): جذع بقشرة ولحاء، جذور وأغصان متفرعة، وأوراق على بطاقات شفافة. **صخور** غير منتظمة بأوجه حادة وخامة صخرية. عشب بحُزَم نصلية وأزهار.
- **بطل مفصّل متحرك** (رجل ملتحٍ: قميص زيتوني، أحزمة جلدية، بنطال كارغو، حذاء، قفازات بلا أصابع، وشاح، حقيبة ظهر مع فراش، فأس): حركات الوقوف والمشي والجري والقفز والانحناء وقطع الأشجار وجمع الحجارة وحملها والتصويب (وضعية) والبناء.
- إضاءة Filmic، ظلال، ليل/نهار، ضباب، كاميرا سينمائية فوق الكتف.
- **البناء بلعبة تركيب بالسحب والإفلات** بقطع حجرية مخرّمة الخامة.
- جمع حجارة (6 لكل صخرة) وخشب (3 لكل شجرة)، حفظ تلقائي ويدوي، جودة، واجهة عربية RTL.
- كل الخامات تُولَّد بالسكربت `tools/gen_textures.py` (بلا أصول خارجية).

## غير منفّذ بعد
الصيد، الحظيرة، الزراعة، شجرة التقنيات، الصوت، الإنجليزية، إعلانات Start.io الحقيقية.
نماذج الشخصية/الأشجار الواقعية في صور المرجع تحتاج أصولًا مرخّصة (glb) تُضاف لاحقًا في `assets/`.

## البناء
1. ارفع المجلد إلى GitHub (انظر أدناه). 2. تبويب Actions ← Build Android APK ← Run workflow. 3. نزّل `wild-origin-apk` من Artifacts.
- التوقيع النهائي: أضف Secrets: `RELEASE_KEYSTORE_BASE64`, `RELEASE_KEY_ALIAS`, `RELEASE_KEYSTORE_PASSWORD`.

## الرفع من الهاتف (Termux)
```
pkg install git
cd wild-origin && git init && git add . && git commit -m "init"
git branch -M main
git remote add origin https://github.com/<user>/wild-origin.git
git push -u origin main   # استخدم Personal Access Token ككلمة مرور
```
